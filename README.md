# Enterprise Warehouse Management System

> **WMS + Workforce Productivity Platform**
> Flutter · Supabase · PostgreSQL

---

## Overview

An integrated Warehouse Management System (WMS) for a multi-warehouse company. The system manages inventory, stock transactions, employee task assignments, workforce scheduling, and productivity analytics.

**Platform:** Android (initial release)
**Stack:** Flutter · Supabase · PostgreSQL · Drift · Riverpod · GoRouter

## Development Rules

1. Work on one phase at a time.
2. Never start a new phase without explicit approval.
3. Never expose Supabase Service Role Key in Flutter.
4. All stock changes go through authorized DB functions only.
5. All task state transitions enforced at DB level.
6. See `MASTER_PROMPT_V2.md` Section 32 for full rules.
